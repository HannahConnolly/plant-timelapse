# Struggle log

Short notes on things that went wrong or were easy to get wrong in this repo, so future sessions don't repeat them. One file per struggle, named `YYYY-MM-DD-slug.md` (use the date of the fix or commit).

Each entry has: **What happened**, **Root cause**, **Fix**, **Lesson**. Keep entries short, and link the commit.

The first three entries were reconstructed from git history rather than written at the time.
